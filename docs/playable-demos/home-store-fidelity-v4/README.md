# Home store-fidelity covers v4

This package governs the 38 original homepage and Discover cover images. It replaces the active v3 abstract SVG mapping while retaining v3 as the rollback target.

## Scope

- 38 original stylized mobile-game key-art covers.
- One cover per governed game, 720×1280 JPEG.
- No title text inside the art; Airvana supplies the title overlay.
- No third-party app-store image, logo, character, interface, or brand association.
- No gameplay, CTA, reward, wallet, attribution, settlement, or data-policy change.

## Files

- `campaign-brief.yaml` — structured visual brief.
- `campaign-contract.json` — draft governed contract; external release still requires human approval.
- `prompt-set.md` — shared art direction and all 38 scene directives.
- `asset-manifest.json` — dimensions, bytes and SHA-256 checksums.
- `qa-report.md` — automated and viewport verification evidence.
