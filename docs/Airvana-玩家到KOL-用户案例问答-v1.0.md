# Airvana 玩家到 KOL：用户案例问答

> 版本：v1.0
> 日期：2026-08-11
> 文档状态：产品方案待确认
> 目标：明确玩家升级 KOL 前后，账号、作品、权限、AI 分身、Campaign 和结算如何变化

## 1. 推荐产品模型

采用 **一个账号、永久保留玩家身份、KOL 作为审核后的增强资格**：

- 玩家身份不会因为成为 KOL 而消失。
- “玩家 / KOL”视角切换只改变功能与内容展示，不改变真实权限。
- KOL 资格由服务端 entitlement 决定，前端本地状态不能升级权限。
- KOL 获得全部玩家能力，并增加品牌合作、商业创作、归因和结算能力。
- 玩家同样可以创作并发布 Agentic Playable，但只能发布到 Airvana APP 内，不能承接品牌 Campaign、营销外发或商业结算。

推荐权威字段：

```text
creator_review_status：未申请 / 审核中 / 通过 / 拒绝 / 暂停 / 降级
kyc_status：未认证 / 审核中 / 通过 / 拒绝 / 过期
account_status：正常 / 受限 / 冻结 / 注销中

commercial_entitlement =
  creator_review_status = 通过
  AND kyc_status = 通过
  AND account_status = 正常
```

该公式是推荐方案，仍需产品确认。

## 2. 典型用户案例

### 案例 A：普通玩家创作并站内发布

```text
注册/登录
→ 选择玩家视角
→ 创建 Agentic Playable
→ 添加素材与能力
→ 预览
→ 提交站内审核
→ 发布到 Airvana APP
→ 获得互动、收藏、评论与站内权益
```

边界：

- `createdByRole = player`
- `publishScope = app_only`
- 不出现品牌 Contract、商业 CTA、外部连接器和 KOL 结算。
- 玩家视角不是只读体验模式，而是具备完整站内创作发布能力。

### 案例 B：玩家申请成为 KOL

```text
身份与角色
→ 了解 KOL 权益与责任
→ 填写创作者申请
→ 提交代表作品与授权声明
→ 完成 KYC
→ 平台审核
→ 通过后开放商业 entitlement
```

审核中仍可继续以玩家身份创作和站内发布，不应锁住原有能力。

### 案例 C：KOL 创建新的品牌合作作品

```text
品牌机会/邀请
→ KOL 申请或接受邀请
→ 确认 Campaign Brief
→ 生成并签署 Campaign Contract
→ 创建 Agentic Playable
→ 素材授权与版本审核
→ 获批版本站内发布
→ 人工确认连接器外发
→ 归因证据
→ 对账、结算与复盘
```

KOL 是创作者、所有者和运营者；Agentic Playable 才是持续运行的营销智能体。

### 案例 D：把历史玩家作品用于品牌合作

推荐采用“复制为 KOL 商业版本”，禁止原地升级：

```text
玩家原作品（继续保留）
→ 复制为商业衍生草稿
→ 记录 source_playable_id 与父版本
→ 绑定新的 Campaign Contract
→ 重新确认素材、地区、CTA、奖励、渠道与归因
→ 重新审核
→ 发布新的 KOL 商业版本
```

历史点赞和评论保留在玩家原作品；商业归因只从获批商业版本的有效事件开始。

### 案例 E：KOL 资格暂停或主动降级

```text
触发 KYC 过期/安全风险/授权过期/违规/主动降级
→ 暂停新 Campaign、外发和结算
→ 撤销连接器 Token
→ 暂停 AI 分身外部渠道
→ 保留玩家身份、历史作品和可申诉证据
→ 整改/重认证/申诉
→ 恢复或维持降级
```

账号、KOL 身份、单作品、连接器、AI 分身和结算需要独立控制，不能用一个总开关粗暴清空全部资产。

## 3. 用户案例问答

### Q1：玩家从哪里申请成为 KOL？

**推荐：**“我的 → 身份与角色 → 创作者身份”。功能中心的 KOL 视角可以预览能力，但不能作为升级入口或直接授予权限。

### Q2：申请过程中还能继续作为玩家使用吗？

**可以。**审核中仅锁定 KOL 商业能力，玩家浏览、互动、创作和站内发布保持可用。

### Q3：申请需要提交什么？

**建议待确认：**

- 公开昵称、简介和内容领域。
- 代表作品或外部账号链接。
- 擅长游戏/内容类型与目标受众。
- 头像、肖像、声音和素材授权声明。
- 品牌营销内容规范确认。
- AI 分身身份标识和授权确认。
- KYC 状态及历史风险检查。

### Q4：KYC 是否必须在申请前完成？

**推荐：**可以先提交创作者申请，但只有“创作者审核通过 + KYC 有效 + 账号正常”才开放品牌、连接器、归因和结算。

### Q5：身份证或护照由 Airvana 保存吗？

**不应保存原件。**生产环境由合规 KYC 供应商处理，Airvana 仅保存供应商引用、状态、地区、完成/过期时间和必要审计记录。

### Q6：创作者审核应有哪些状态？

```text
未申请 → 草稿 → 已提交 → 补充材料 → KYC/平台审核中
→ 已通过 / 已拒绝 → 申诉中 → 已暂停 / 已降级
```

每个状态都需要允许动作、禁止动作、时间、原因和下一步。

### Q7：审核通过后 KOL 立即获得什么？

- 创作者中心与商业创作入口。
- KOL AI 分身配置权。
- Campaign 申请/邀请和 Contract 确认。
- 获批项目的归因与结算查看权。
- 获批版本的连接器配置权。

连接器不能“全账号一次授权后任意外发”；还需校验具体 Contract、作品、版本和渠道。

### Q8：切换到 KOL 视角是否等于升级成功？

**不等于。**切换只改变展示。未取得 entitlement 时，点击 KOL 专属动作应显示资格条件并进入申请流程；API 仍必须拒绝越权请求。

### Q9：玩家和 KOL 的创作能力有什么相同与不同？

**相同：**都可以创作、保存草稿、预览、站内审核与站内发布。
**不同：**KOL 可绑定 Campaign Contract、品牌素材、商业 CTA、外部连接器、归因和结算；玩家不能。

### Q10：玩家升级 KOL 后，历史作品会自动成为营销作品吗？

**不会。**历史作品继续保持 `app_only`。不自动绑定品牌、不继承 Contract、不获得连接器或商业收益权。

### Q11：怎样把玩家作品用于品牌合作？

点击“复制为 KOL 商业版本”，保留来源关系并重新走 Contract、素材授权、审核与发布。不要直接覆盖原作品。

### Q12：审核中的玩家草稿会自动升级吗？

**推荐不自动。**草稿保持创建时角色和发布范围。用户可选择继续作为玩家作品，或复制为 KOL 商业草稿。

### Q13：玩家与 KOL 的收益有什么区别？

- 玩家：站内积分、徽章、体验资格等站内权益，具体是否可兑换由单独规则决定。
- KOL：在 Campaign Contract、KYC、归因证据、审核和结算条件满足后，获得获批商业服务结算。
- 邀请人数、浏览、点赞不能直接等同收入。
- AIP 站内权益与 KOL 商业结算应分账。

### Q14：KOL 被暂停时，已产生的收益怎么办？

**推荐：**已验证且无争议的部分保留；未验证事件停止入账；涉嫌作弊部分冻结复核；暂停不能无理由清零全部历史权益，并需提供申诉。

### Q15：玩家什么时候可以配置 KOL AI 分身？

申请人可提前配置未公开草稿，但只有创作者资格和必要授权有效后才能公开启用、代表项目答疑或连接外部渠道。

### Q16：个人资料与 AI 分身资料是否同步？

首次创建可以一次性复制公开资料；创建后独立编辑。修改个人昵称、头像或简介，不应自动覆盖已审核分身版本。

### Q17：一个 KOL 可以有几个 AI 分身？

推荐模型：一个主分身 + 多个场景分身。中文、英文、韩语可分别配置声音和话术；不同 Campaign 的知识与权限必须隔离。

### Q18：AI 分身能否直接使用品牌知识或自动发布？

**不能默认使用或自动发布。**只能读取绑定 Contract 授权知识；外部回复、私信、发布和收益表达需单独授权和人工确认，并持续显示“AI 分身”身份。

### Q19：申请被拒绝后怎么办？

结果页应展示原因分类、不通过项、是否可补充、最早重提时间、申诉入口和审核记录编号。拒绝不影响玩家继续站内创作。

### Q20：如何申诉？

```text
查看理由 → 补充证据 → 提交申诉 → 独立复核
→ 维持原判 / 恢复审核 / 通过
```

申诉期间不临时恢复商业权限。

### Q21：什么情况会暂停 KOL？

- KYC 过期或失效。
- 账号安全或合规风险。
- 肖像、声音、品牌素材授权过期。
- Campaign 违规或多次审核失败。
- 虚假归因、作弊、异常流量。
- AI 分身越权发言。
- 连接器授权失效。

### Q22：暂停后账号会怎样？

继续保留玩家身份、站内创作和历史作品；停止新品牌合作、外部发布、商业结算和 AI 分身外部渠道。违规作品可单独下架，不自动删除全部内容。

### Q23：用户可以主动降级回玩家吗？

**推荐支持。**降级时取消新合作、撤销外部 Token、暂停分身公开渠道，保留历史合同和审计；运行中的商业作品按 Contract 决定归档、暂停或移交。

### Q24：KYC 过期是否直接删除 KOL 身份？

**推荐不删除身份，限制商业权限：**可继续普通站内创作，但不能新建 Contract、外发或结算；重新认证后恢复。

### Q25：用户删除账号时怎么处理？

必须分别处理个人资料、玩家作品、商业版本、AI 分身、Campaign Contract、连接器授权、KYC 引用和依法需要保留的合同/反欺诈证据，并明确告知删除、匿名化和依法保留结果。

## 4. 需要补齐的异常闭环

1. KOL 申请材料、评分标准和审核 SLA。
2. 补充材料、拒绝、重提和申诉。
3. KYC 过期、重认证和供应商异常。
4. 暂停、恢复、主动降级和账号冻结的区别。
5. 玩家作品复制为商业版本的 lineage 与数据边界。
6. 连接器 Token 失效、撤销和外部已发布内容处理。
7. AI 分身肖像/声音授权到期、版本回滚和人工接管。
8. 归因异常、作弊、结算冻结、税务、退款和争议。
9. 单作品删除、逐 Playable 档案删除和全账号删除。
10. 商业作品在 KOL 离开平台后的归档、暂停或移交。

## 5. 验收用例

- 未认证玩家切换 KOL 视角，真实权限不变。
- 创作者审核通过但 KYC 未完成，品牌、连接器和结算仍锁定。
- 玩家能完成站内创作发布，但外发/品牌/营销动作必须失败关闭。
- 历史玩家作品升级后仍保持 `app_only`。
- 复制为商业版本后保留来源，但重新走 Contract 与审核。
- KYC 过期停止新商业动作，不删除玩家作品。
- KOL 暂停时连接器、结算和 AI 分身外部渠道同步暂停。
- 申诉提交后不自动恢复权限。
- 主动降级后仍能作为玩家使用。
- 删除账号后 Airvana 业务存储中不可恢复身份证/护照原图。

## 6. 待确认的关键决策

1. 是否采用“审核通过 + KYC 有效 + 账号正常”的商业权限公式。
2. 是否确认玩家历史作品只能复制为商业版本，禁止原地升级。
3. KOL 申请材料、审核标准、SLA、重提与申诉规则。
4. KOL 暂停、恢复、主动降级和 KYC 过期的权限矩阵。
5. 玩家站内权益与 KOL 商业结算的分账规则。
6. 商业作品在 KOL 离开、降级或删除账号后的处理方式。
