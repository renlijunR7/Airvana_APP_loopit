## 评测门禁

1. **独立性**：24 个目标游戏均解析到独立、版本化的玩法背景，不再使用商店封面降级。
2. **视觉保真**：主体清楚、透视一致、材质可信、无伪文字、无明显生成瑕疵。
3. **玩法可读性**：中央交互区、路径/槽位/车道/目标层级与对应玩法一致。
4. **移动端**：360×800、390×844、430×932 无关键区域裁切、无横向溢出。
5. **运行时**：素材加载成功，Canvas 可交互，成功/失败/暂停/重试/退出不回归。
6. **清单完整性**：每个资产记录 asset_id、路径、来源、所有者、授权状态、语言、SHA-256、版本、到期/限制和审核状态。
7. **授权边界**：自动检查只可给出 `technical_review_passed`；商业发布状态必须由人工审核决定。
