# 果园合合塔 v2 · 本地 Demo 美术与交互说明

## 目标

在不改变 `plb_orchard_merge` 三阶段状态机的前提下，将数字圆点占位棋盘升级为可读、可玩的休闲合成游戏界面。

## 资产规划

- 背景：竖屏果园工作台，中央低细节区域承载棋盘。
- 果实图集：青苹果、金梨、红苹果、蜜桃、紫李、黄金果王六级，横向等分图集。
- UI：深绿任务头、奶油色信息卡、5×5 果箱、珊瑚色选中态、绿色等级进度。
- 反馈：选中描边、错误保留第二选项、合成粒子、连击提示、音效、暂停与重开沿用运行时。

## 玩法闭环

1. 选择一个果实。
2. 再选择相邻且同级的果实完成合成。
3. 合成后目标格升级，起始格补充 1—2 级果实并扣除一步。
4. 达到阶段目标进入下一阶段；三阶段完成即成功。
5. 步数耗尽则失败，可从 Airvana 外层控制重新开始。

所有新增图像均为本地 Demo 资产，未进入品牌授权、商业审核或外部分发流程。界面仅显示 `LOCAL DEMO`，不制造奖励、上链或全网发布成功的假象。
