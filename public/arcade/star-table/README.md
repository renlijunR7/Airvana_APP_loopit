# 星桌竞猜

基于用户提供的 SUD 竞猜玩法宣传截图制作的原创、可玩的移动端 H5 复刻。作品保留了参考中的四段式体验：

`预约竞猜 → 实时竞猜 → 游戏中 → 竞猜结算`

本项目不是原产品源码，也不接入 SUD SDK、真人房间、现金、充值、提现或任何可兑换奖励。所有星币均为本机演示数据。

## 直接运行

在本目录执行：

```bash
python3 -m http.server 4189 --bind 127.0.0.1
```

浏览器打开：

```text
http://127.0.0.1:4189/
```

## 玩法

1. 在活动页点击“预约竞猜”。
2. 封盘前选择一名支持的玩家与 100 / 200 / 400 星币。
3. 点击确认后，竞猜券被锁定并扣除对应的演示星币。
4. 六名 AI 玩家自动出牌；最先将手牌出完的玩家获胜。
5. 猜中会返还本次星币的 5 倍，例如 400 → 2,000；未猜中只损失本次星币。
6. 结算后可回看牌桌、查看战报或开始下一局。

点击左上角“星桌”可查看规则或重置本地演示进度。

## 已实现

- 手机优先的全屏竖版布局，兼容安全区与减少动画偏好。
- 活动入口、六人选择、实时倒计时、三档星币与封盘锁定。
- 带种子的可重复 AI 牌局、唯一赢家、命中与未命中结算。
- 三星庆祝、`+2,000` 命中反馈、本局前三名与历史战报。
- 余额与历史的 `localStorage` 持久化及安全恢复。
- 防重复下注、防重复结算、余额不足和无效操作提示。
- 轻量 Web Audio 反馈，可随时关闭；无外部音频依赖。

## 项目结构

```text
index.html             页面入口与语义结构
styles.css             移动端视觉、牌桌与动画
src/app.js             UI 事件、计时与声音
src/engine.js          纯状态机与确定性牌局逻辑
src/render.js          四阶段页面与弹层渲染
src/storage.js         本地保存、恢复与校验
assets/                原创角色头像和图标
tests/engine.test.js   状态机、结算与存储测试
ASSETS.md              素材来源说明
QA.md                  验收证据与复刻边界
```

## 测试

```bash
npm test
```

测试覆盖阶段流转、下注扣款、余额不足、5 倍命中派彩、猜错、结算幂等、下一局与持久化。

## 复刻边界

参考截图没有给出底层牌类游戏的完整规则、赔率配置、房间同步、聊天、支付、后台接口或失败页。当前版本采用“六名 AI 玩家竞速出完手牌”的单机机制来完整承载可观察的竞猜流程；详情见 `QA.md`。
