# SUD 德州扑克移动端复刻

这是一个零依赖、可直接运行的移动端 H5 复刻。默认首屏锁定为参考截图中的状态：房间 `小白专场22`、底牌 `2♣ / 4♠`、多萝西下注 `22`、本家下注 `44`、本家余额 `94`、底池 `0`。

## 运行

在本目录执行：

```bash
npm run preview
```

然后打开：

```text
http://127.0.0.1:4192/
```

也可以使用任意静态 HTTP 服务器。请勿直接通过 `file://` 打开，因为浏览器会限制 ES Modules。

## 操作

- 点击本家底牌或绿色“北”头像，进入当前回合。
- 可选择弃牌、跟注/让牌、加注；加注支持快捷额度和滑杆确认。
- 跟注后依次进入翻牌、转牌、河牌和摊牌，最后显示中文牌型与结算。
- 顶部按钮支持挂起/继续、游戏选择、重新开局、规则和战绩。
- 底部支持静音切换、聊天、礼物动效；右下支持“猜自己赢”。

## 验证

```bash
npm test
```

规则测试覆盖 10 种牌型、7 选 5、A2345 顺子、踢脚牌、平局、重复牌和确定性洗牌。
