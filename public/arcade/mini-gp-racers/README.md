# Mini GP Racers · 本地复刻版

这是一个可离线运行的浏览器赛车游戏，按 Mini GP Racers 的可观察玩法、界面和美术方向重新实现。当前版本已接入原作发行包中的方程式赛车 GLB 和 1254×1254 游戏图标，并打包、预加载 10 张原作赛道/场景纹理；比赛场景实际使用其中的沥青、草地、碎石、观众及两类树木纹理。

首场赛道中心线使用从原作运行数据提取的 SPA 65 个控制点，经归零并按 0.25 比例统一缩放；道路网格、山体、护栏、广告、建筑、比赛逻辑、界面代码、车辆变体和音频仍由本项目实现。因此当前交付不代表完整 1:1 复刻，部分物体布局、车辆套件、物理手感、音效和界面细节仍可能与原作不同。

## 当前素材接入

- 赛车：`assets/original/f1car-2026.glb`，8 辆车共用基础模型，并在本地按车型颜色、尺寸和套件参数区分。
- 场景：完整打包并预加载沥青、草地、碎石、观众、昼/夜建筑立面、3 类树木和灌木共 10 张 PNG；当前日间赛道渲染使用其中 6 张。
- 赛道：首场采用原作 SPA 中心线数据的 0.25 比例版本，实算长度约 1753.37 米；车道半宽 6.5 米，护栏位于中心线两侧约 16 米。
- 图标：`assets/original/mini-gp-racers-logo.png`，1254×1254 PNG，用于启动页、页签图标和品牌入口。
- 素材来源、提取日期、校验值与授权边界见 [`ASSETS.md`](ASSETS.md)。

## 玩法

- 从第 12 位出发，在限时单圈挑战中完成指定超车数；8 个挑战逐步提高目标和奖励。
- 赛道分布 BTC、ETH、USDT、SOL、BNB、DOGE、USDC 七种视觉拾取物；它们只代表等值街机奖励，不代表真实币价、余额或链上转账。
- 桌面端：`W`/`↑` 油门，`S`/`↓` 刹车；停稳后继续按住刹车即可倒车。`A D`/`← →` 转向，按住 `Shift` 漂移，`空格` 使用 OVR，`V` 切换 ERS 模式，`C` 切换镜头，`Esc` 暂停。
- 手机和平板：使用屏幕下方的方向、漂移、油门、刹车/倒车和 OVR 按钮；横屏体验最佳，竖屏也可游玩。
- 漂移按钮在桌面与手机均常驻左下方：保持前进并转向时按住按钮或 `Shift`，出现侧滑、轮胎烟雾和亮色反馈；松开后恢复抓地。低速、倒车或草地上不会触发漂移。桌面按钮旁显示 WASD 对照提示。
- 赛车币可购买赛车、升级发动机/尾翼/轮胎并解锁配色；进度保存在浏览器 `localStorage`。

## 运行

```bash
cd /path/to/game
npm run serve
```

然后打开 `http://127.0.0.1:4191/`。

## 验证

```bash
npm test
```

建议在 1440×900、844×390、390×844 三种视口检查车库、发车灯、比赛、漂移/倒车、暂停和赛后结算流程。首关是 55 秒限时超车挑战，不要求在时限内跑完约 1.75 公里的整圈。当前实际验收状态及待验项目见 [`QA.md`](QA.md)。
