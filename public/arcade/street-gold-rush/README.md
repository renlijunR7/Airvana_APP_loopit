# 街区淘金大冲刺

一款参考《Talking Tom Gold Run》核心节奏、但使用原创代码绘制角色与场景的移动端优先三车道跑酷游戏。

## 运行

请在本目录启动静态服务器，不要直接双击 `index.html`：

```bash
python3 -m http.server 4175 --bind 127.0.0.1
```

然后打开 <http://127.0.0.1:4175/>。

## 操作

- 手机：左右滑动换道、上滑跳跃、下滑滑铲。
- 键盘：方向键或 WASD；空格跳跃；P / Esc 暂停。
- 收集磁铁、护盾、双倍金条和喷气背包；Boss 阶段跳起把炸弹踢回。
